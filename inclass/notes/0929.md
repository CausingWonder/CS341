### Const Qualifier
- Specifies that the value can not be changed
- Applicable to all declarations
- Const functions: a compiler error will occur if there are any attempts to change a member variable of the class

### Inline Files
- Organization tool for C++
- Reduces code clutter 
- Placed in header file and expands in the source file
- Can template functions
- Replaced at compile time and not runtime

### Friends
- Can be declared with methods and classes
- Friend functions are of a class which is defined outside the class scope, but has equal permissions
- Friends provide access to "something", Inheritance provides an "is-a" relationship

### Copy Constructor
- A constructor that creates an instance by initializing it with the same class
