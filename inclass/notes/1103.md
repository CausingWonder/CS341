#### 3 Rules
- N is greater then all in the left sub tree
- N is less then all in the right sub tree
- Both left and right are binary search trees
#### Full Binary Tree
- All nodes are at a level less than h has 2 children each
- Height, h >= 0 has 2^h -1 nodes. This is the maximum height with a given amount of nodes
- You can not add nodes to a full binary without increasing it's height
#### Complete Binary Tree
- Binary tree which is full down to level h-1, while level h is filled in from left to right
- When a node at level h-1 has one child it is a left child
#### Fully Balanced
- The height of any nodes right sib tree differs from the height of the node's left subtree by no more than 1
#### Binary Trees
- Each node will have a pointer to two children nodes
- If both children of a node are nullptr then the node is a leaf node
#### Red-Black Tree
- All the same properties of BST
- Each node has a color, Red/Black which aids in maintaining balance 
- 6 rules of RBT
	- 1: All RBT must be a type of BST
	- 2: The root of the entire tree is Black
	- 3: Every node when inserted begins as a Red node
	- 4: If a node is red then its children must be black, no adjacent red nodes
	- 5: Every path from a node to a nullptr must contain the same number of black nodes
	- 6: Every leaf node, nullptr must be black
